La trasposizione a colonne in PHP

Scrivi in PHP le funzioni che cifrano, decifrano e attaccano la trasposizione a colonne con parola chiave. Lavori nel file esercizio.php; il file test.php controlla il tuo codice con dei casi noti.

Prima di iniziare

Il cifrario. Le lettere non cambiano, cambia l'ordine. Regole usate in questo laboratorio:

  1. il testo si riduce alle sole lettere A-Z maiuscole (si scartano spazi, punteggiatura, cifre e accenti);
  2. si scrive nella griglia per righe, larga quanto la chiave;
  3. se l'ultima riga è incompleta si aggiunge X fino a riempirla;
  4. si leggono le colonne dall'alto in basso, nell'ordine alfabetico delle lettere della chiave; a parità di lettera, prima la colonna più a sinistra.

Esempio: ATTACCOALLALBADOMANI con chiave ZEBRA (5 colonne, 4 righe). Le colonne si leggono nell'ordine A, B, E, R, Z, cioè dalle posizioni [4, 2, 1, 3, 0].

Gli indici della griglia. Il testo è una stringa, non una matrice. La lettera in riga r e colonna c di una griglia larga n sta nella posizione $r * $n + $c. Verificalo a mano sull'esempio.

Livello 2 Scrivi l'inversa

Scrivi decifraTrasposizione(string $cifrato, string $chiave): string. Restituisce il testo con le eventuali X di riempimento ancora in fondo (non devi toglierle).

  • Numero di righe = lunghezza del cifrato ÷ lunghezza della chiave.
  • Il cifrato è fatto di blocchi da «righe» lettere: il blocco p è la colonna ordineColonne($chiave)[$p].
  • Se la lunghezza non è multipla della chiave, lancia InvalidArgumentException.

Prova a mano: il cifrato ACAT LALA (senza spazio, 8 lettere) con chiave BA ha ____ righe; il primo blocco è e va nella colonna numero ____.

Livello 3 Scrivi l'attacco

Non conosci la chiave, ma sai che nel messaggio compare una parola probabile. Nel file trovi già scritta permutazioni(array $v), che restituisce tutti i riordinamenti di un array: ogni riordinamento di [0, 1, …, n−1] è un possibile ordine delle colonne.

Scrivi attaccoTrasposizione(string $cifrato, string $parola, int $maxColonne = 7): array:

  1. per ogni larghezza n da 2 a $maxColonne che divide la lunghezza del cifrato;
  2. per ogni ordine delle colonne, ricostruisce il testo;
  3. se contiene la parola (senza distinguere maiuscole e minuscole) lo aggiunge all'elenco.

L'elenco restituito non ha doppioni ed è in ordine alfabetico (sort()); se nessun testo contiene la parola è vuoto.
