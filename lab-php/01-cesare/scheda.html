Il cifrario di Cesare in PHP

Scrivi in PHP le funzioni che cifrano, decifrano e attaccano il cifrario di Cesare. Lavori nel file esercizio.php; il file test.php controlla il tuo codice con dei casi noti.

Prima di iniziare

Il cifrario. Ogni lettera si sposta di k posti nell'alfabeto, ripartendo da A dopo la Z. Con le posizioni A=0, B=1, … Z=25 la regola è (x + k) mod 26. Le lettere maiuscole restano maiuscole, le minuscole restano minuscole, tutto il resto (spazi, cifre, punteggiatura) non cambia.

Attenzione ai negativi. In PHP il resto di un numero negativo è negativo: -3 % 26 vale -3, non 23. Come si ottiene sempre un valore tra 0 e 25?

Livello 1 Completa la funzione

In esercizio.php trova la funzione cesare(string $testo, int $k): string e sostituisci i tre TODO. Lo scheletro è questo:

function cesare(string $testo, int $k): string
{
    // TODO 1: porta $k nell'intervallo 0..25
    $k = $k;

    $risultato = '';
    for ($i = 0; $i < strlen($testo); $i++) {
        $c = $testo[$i];
        if ($c >= 'A' && $c <= 'Z') {
            // TODO 2: cifra la maiuscola (ord, % 26, chr)
            $risultato .= $c;
        } elseif ($c >= 'a' && $c <= 'z') {
            // TODO 3: stessa cosa per le minuscole
            $risultato .= $c;
        } else {
            $risultato .= $c;     // spazi, cifre, punteggiatura
        }
    }
    return $risultato;
}

Prima di scrivere, rispondi a mano: con k = 3, qual è il numero ottenuto da ord('X') - 65 + 3? E quale lettera si ottiene dopo % 26 e + 65?

Livello 3 Scrivi l'attacco a forza bruta

Un messaggio cifrato con Cesare ha solo 25 chiavi possibili. Scrivi due funzioni:

  1. forzaBruta(string $cifrato): array prova tutte le chiavi da 1 a 25 e restituisce un array con la chiave come indice e il testo decifrato come valore, cioè [1 => '…', 2 => '…', …, 25 => '…'].
  2. trovaChiave(string $cifrato, string $parola): ?int usa forzaBruta() e restituisce la chiave per cui il testo contiene la $parola (senza distinguere maiuscole e minuscole), oppure null se nessuna va bene. Ti può servire stripos().
Una parola che sai (o immagini) essere nel messaggio, come «attacco» o «ciao», si chiama parola probabile: è un indizio molto potente per chi attacca un cifrario.

Per riflettere: perché forzaBruta() parte da 1 e non da 0? Quante volte, al massimo, deve ripetere il ciclo?
