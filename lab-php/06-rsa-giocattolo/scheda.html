RSA giocattolo in PHP

Scrivi in PHP le funzioni che generano le chiavi RSA, cifrano e decifrano, e poi rompi una chiave troppo piccola. Lavori nel file esercizio.php; il file test.php controlla il tuo codice con dei casi noti.

Prima di iniziare

Gli ingredienti. Li trovi nelle slide del modulo 7 (matematica) e del modulo 8 (RSA). Con l'esempio p = 61, q = 53, e = 17:

Limite degli interi. In PHP un int ha 64 bit (massimo circa 9,2 · 1018). Nelle moltiplicazioni modulari il prodotto di due numeri minori di n deve stare in un int: l'esercizio funziona per n fino a circa 3 miliardi. Le chiavi vere (2048 bit) richiedono numeri molto più grandi: in PHP si usano le estensioni GMP (gmp_powm, gmp_invert) o bcmath (bcpowmod), oppure openssl.

Livello 1 Completa le funzioni

In esercizio.php sostituisci i TODO 1 e TODO 2:

  • mcd(int $a, int $b): int: algoritmo di Euclide con un ciclo while.
  • potenzaModulare(int $base, int $esp, int $mod): int: square-and-multiply. Non calcolare mai $base ** $esp: sarebbe un numero enorme.

Livello 2 Scrivi le funzioni di RSA

Scrivi il corpo di queste funzioni (nomi e firme sono fissati nel file):

  1. euclideEsteso(int $a, int $b): array restituisce [g, x, y] con $a*x + $b*y = g.
  2. inversoModulare(int $a, int $m): ?int usa euclideEsteso(); restituisce null se mcd è diverso da 1. Attenzione ai numeri negativi!
  3. generaChiavi(int $p, int $q, int $e): ?array restituisce ['n', 'phi', 'e', 'd'], oppure null se e non è coprimo con φ.
  4. cifra() e decifra(): usano potenzaModulare().

Livello 3 Scrivi l'attacco

Un attaccante conosce solo la chiave pubblica (n, e). Scrivi:

  1. fattorizza(int $n): array restituisce [p, q] provando i divisori fino a √n (oppure [] se n è primo).
  2. attaccoRSA(int $n, int $e): ?int restituisce la chiave privata d a partire da n ed e.

Per riflettere: quante divisioni al massimo fa fattorizza() con n = 3233? E con un n di 13 cifre? Che cosa succederebbe con un n di 617 cifre (RSA-2048)?
